## On-Scroll Image Distortion and Grain Effect

An interactive WebGL image gallery exploring on-scroll distortion and procedural rain.

[Demo](http://001-shaders-on-scroll.netlify.app)

### Installation, run the following commands:

```bash
bun install

bun dev
```

### If you do not have bun installed, delete the `bun.lock` file and install via npm,

```bash
npm install

npm run dev
```
